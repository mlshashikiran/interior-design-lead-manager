Editor

  • E1 One row per line: handle · item name · W · H · Area/Qty · Unit · Rate · Total · actions. Row height ≈ 52px. Description, item code and category live in a "Details" expander (chevron at row end).
  • E2 Rate input is ≥128px, right-aligned, shows ₹ prefix, thousands separators on blur, raw number on focus. Width/Height/Area use 2 decimals. When W/H are 0/empty, they show disabled "n/a" and Area/Qty is the editable driver.
  • E3 Every icon button has aria-label + visible tooltip. Reordering via drag handle (keep ↑↓ in the row menu for keyboard users). Delete removes immediately and shows an Undo toast for 6s – no confirm dialog.
  • E4 Catalogue-derived code/category render as read-only dashed chips with label "From catalogue".
  • E5 Totals card is sticky (top:78px) in a right column ≥1100px; stacks below on narrow screens. Section-wise and Wood/Others summaries collapse to compact lists – no 300px empty cards.
  • E6 Page has ≥120px bottom padding; footer never covers the last row.
  • E7 Autosave status: “Saving…” (amber pulse) → “Saved just now / 2 min ago” (green) → “Unsaved changes” (red) on error. Leaving with unsaved changes prompts.
  • E8 Footer: revision note field + primary button labelled with the revision it creates (“Save as R03”). Running grand total always visible in the footer.

View

  • V1 Tiles: customer (+phone, location), project/studio, status + revision + validity, grand total with subtotal+GST breakdown.
  • V2 Header actions: Preview / Print · Download ▾ (PDF, CSV, XLSX) · primary Edit quotation.
  • V3 Revisions as a timeline: label, status of current, amount, Δ vs previous (▲ green / ▼ red), author, short date, note, actions Compare / Preview / Restore.
  • V4 Non-applicable dimensions render “—” not “0.00”. Remove the stray empty strip under the section card. Add a right-hand totals card so GST and grand total sit beside the lines.

  • L5 Sortable column headers (aria-sort). Whole row clickable (keep real link for middle-click). Kebab menu: Open, Duplicate, Download PDF, Archive.

Global

  • G2 Visible :focus-visible ring on every control.

Acceptance checks

  • Two line items fit on screen without scrolling at 1440×800 together with customer card collapsed.
  • Rate 1,23,456.50 displays fully (no clipping) at 1280px width.
  • Changing any W/H/Qty/Rate updates row total, section subtotal, totals card and footer total in the same tick.
  • Deleting a line is undoable for 6 seconds; totals revert.
  • Tab order: name → W → H → Qty → Unit → Rate → row actions; Enter in Rate adds focus to next row’s name.
  • Cancel with unsaved changes asks to discard; with none, exits silently.
  • No horizontal page scroll at 360px.

Calculation rules (as in current app)

  • Area = W × H when both > 0, else Qty entered manually.
  • Line total = Area/Qty × Rate. Section subtotal = Σ line totals.
  • Soft-close addition = 5% of Wooden subtotal when enabled.
  • GST 18% on (Total − Discount). Round off to nearest ₹1; Grand total = after GST + round off.
  • Wood vs Others split is by item category (wood-type categories vs accessories).
